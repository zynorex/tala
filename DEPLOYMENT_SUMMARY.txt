A RIGID, immutable vault lock/unlock state machine has been implemented to
prevent the critical security failure of "vault appears accessible when locked."

The system enforces time-locks at database and application level with:
✅ Strict state transitions (LOCKED → WAITING → UNLOCKED)
✅ Mandatory time verification before file access
✅ Complete audit trail of all unlock attempts
✅ Zero bypasses (not even for admins)
✅ Comprehensive test coverage (20+ unit tests)

              ┌──────────────┐

                     │

                     │
            ┌────────▼────────┐

            └────────┬────────┘
                     │
            ┌────────▼────────┐
            │   UNLOCKED      │ After unlockTime
            └────────┬────────┘
                     │
            ┌────────▼────────┐
            │   DECRYPTED     │ After file access
            └─────────────────┘

SIDE TRANSITIONS (From Any State):
  → VOIDED (manual deletion)
  → EXPIRED (demo vault past expiry)

CRITICAL PROPERTY:
  ⚠️  States are IRREVERSIBLE - Cannot go backwards
  ⚠️  No bypasses for any user (including admins)
  ⚠️  Database is source of truth (not client time)

🔒 checkVaultUnlockEligibility(vaultId, userId)
   Purpose: PRIMARY SECURITY CHECK - Is vault accessible NOW?
   Returns: { canUnlock, status, timeRemaining, message }
   Critical: ✅ YES - DO NOT BYPASS
   
   Usage:
   const result = await checkVaultUnlockEligibility({
     vaultId: 'vault-123',
     userId: 'user-456'
   });
   
   if (!result.canUnlock) {
     throw new Error(result.message);
   }

🔓 verifyUnlockBeforeFileAccess(vaultId, userId, ipAddress, userAgent)
   Purpose: Verify unlock before file download/viewing
   Returns: { allowed, reason }
   Critical: ✅ YES - CALL BEFORE EVERY FILE OPERATION
   
   Usage:
   const { allowed } = await verifyUnlockBeforeFileAccess(
     vaultId,
     userId,
     req.ip,
     req.headers['user-agent']
   );
   
   if (!allowed) {
     return Response.json({ error: 'Access denied' }, { status: 403 });
   }

📝 recordUnlockAttempt(vaultId, userId, status, failureReason)
   Purpose: Log unlock attempt to audit trail
   Called: Automatically by verification functions
   Returns: Promise<void>
   
   Usage (if manual):
   await recordUnlockAttempt(vaultId, userId, 'FAILED', 'Vault locked');

📊 logUnlockActivity(vaultId, userId, action, description, ipAddress, userAgent)
   Purpose: Log activity for compliance
